# THƯ MỤC LƯU TRỮ ẢNH SẢN PHẨM GỐM SỨ MINH HUYỀN
=====================================================
Bạn có thể chép trực tiếp các file ảnh chụp thật của xưởng vào thư mục này:
Ví dụ:
- public/images/products/bat-huong-song-long.jpg
- public/images/products/am-chen-men-ran.jpg
- public/images/products/binh-hut-loc.jpg

Khi bạn chép ảnh vào đây, trên website bạn chỉ cần điền đường dẫn:
/images/products/bat-huong-song-long.jpg
(Hệ thống Next.js sẽ tự động phục vụ các file tĩnh trong thư mục public).

Ngoài ra, bạn cũng có thể bấm nút "Đổi ảnh / Sửa" ngay trên trang chủ hoặc trong Bảng Quản Trị
và chọn nút "Tải ảnh từ máy" để tự động nén và tải ảnh lên trực tiếp!
